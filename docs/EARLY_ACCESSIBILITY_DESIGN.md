# External temporal accessibility analysis

The external-time analysis is complete. Its implemented definitions, preprocessing and reproduction command are in [Temporal Methods](TEMPORAL_METHODS.md); actual results and figure legends are in [Temporal Results](TEMPORAL_RESULTS.md).

The reference uses actual 0/24/48/72-hour measurements rather than an inferred pseudotime. The strongest module reaches half its opening amplitude at 24-48 hours; it is not relabeled as the earliest-opening group. All earliest-20/25/33-percent sensitivities remain in the released tables.
